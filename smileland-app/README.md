# SMILELAND (สไมล์แลนด์ · ที่ดินยิ้ม) — ระบบฝากขาย ฝากเช่า บ้านและที่ดินทั่วประเทศ

ระบบต้นแบบที่ใช้งานได้จริง: หน้าเว็บ 13 เมนู + API + ระบบแอดมินอนุมัติ + จดหมายเหตุที่ดิน
ใช้ Node.js อย่างเดียว **ไม่ต้องติดตั้งแพ็กเกจเพิ่ม (ไม่มี npm install)** ข้อมูลเก็บเป็นไฟล์ JSON

## วิธีรันบน Windows
1. ติดตั้ง **Node.js LTS** (เวอร์ชัน 18 ขึ้นไป) จาก https://nodejs.org แล้วกด Next จนเสร็จ
2. แตกไฟล์ zip ไว้ที่โฟลเดอร์ใดก็ได้ แล้ว **ดับเบิลคลิก `start.bat`**
3. เบราว์เซอร์จะเปิด http://localhost:3000 (ถ้าไม่เปิด ให้พิมพ์เอง) — ปิดหน้าต่างดำเพื่อหยุดระบบ
4. หน้าแอดมิน: **http://localhost:3000/admin**
   - ครั้งแรกระบบจะสร้างบัญชี `admin` พร้อมรหัสผ่านสุ่ม แสดงในหน้าต่างดำ และบันทึกไว้ที่ `data/ADMIN-FIRST-LOGIN.txt`
   - เข้าสู่ระบบแล้วไปที่แท็บ “เปลี่ยนรหัสผ่าน” (ไฟล์ ADMIN-FIRST-LOGIN.txt จะถูกลบอัตโนมัติเมื่อเปลี่ยนรหัส)
   - ลืมรหัสผ่าน: หยุดระบบ ลบไฟล์ `data/admin.json` แล้วเปิดใหม่ ระบบจะสร้างรหัสใหม่
- เปลี่ยนพอร์ต: `set PORT=8080` ก่อน `node server.js`
- Mac/Linux: `node server.js`

## โครงสร้างไฟล์
- `server.js` — เว็บเซิร์ฟเวอร์ + API (http/fs/crypto ของ Node เท่านั้น)
- `public/` — หน้าเว็บ (index, search, listing, post, promote, agents, consign, services, seo, tools, news, app, about, contact, status, admin) และ `assets/style.css`, `assets/app.js`, `assets/admin.js`
- `data/records.json` — จดหมายเหตุที่ดินทุกแปลง (ประกาศตัวอย่าง 16 รายการถูกสร้างอัตโนมัติครั้งแรก ระบุ “ข้อมูลตัวอย่าง”)
- `data/admin.json` — บัญชีแอดมิน (รหัสผ่านเก็บแบบ hash scrypt)
- `uploads/` — รูปที่ผู้ใช้อัปโหลด
- `tools/gen.py` — สคริปต์สร้างหน้า HTML (ไม่จำเป็นต่อการรัน; แก้หน้าแล้วรัน `python tools/gen.py`)

## สำรองข้อมูล
คัดลอกโฟลเดอร์ `data/` และ `uploads/` ไปเก็บไว้ (แนะนำทุกวัน) — กู้คืนโดยวางทับแล้วเปิดระบบใหม่
ไฟล์เขียนแบบ atomic (เขียนไฟล์ชั่วคราวแล้วเปลี่ยนชื่อ) ลดโอกาสไฟล์เสียเมื่อไฟดับ

## สิ่งที่ใช้งานได้แล้ว
- ฟอร์ม **ฝากขาย/ฝากเช่า** (consign.html) และ **ลงประกาศ** (post.html) ส่งเข้า API พร้อมอัปโหลดรูป (JPG/PNG/WEBP ตรวจจากเนื้อไฟล์, ≤5MB/รูป, ≤8 รูป) ตรวจข้อมูลฝั่งเซิร์ฟเวอร์ → สถานะ “รอพิจารณา” ได้เลขอ้างอิง
- **ตรวจสอบสถานะ** (status.html) ด้วยเลขอ้างอิง + เบอร์โทร เห็นเหตุผลเมื่อไม่อนุมัติ/ขอข้อมูลเพิ่ม
- **แอดมิน** (/admin): ล็อกอิน (scrypt + cookie HttpOnly SameSite=Strict + CSRF token), แดชบอร์ดนับสถานะ, คิวรอพิจารณา, อนุมัติ → ขึ้นหน้าค้นหาทันที, ไม่อนุมัติ/ขอข้อมูลเพิ่ม (ต้องใส่เหตุผล), ขายแล้ว/ให้เช่าแล้ว, ปิดเผยแพร่, ตั้งประกาศเด่น, เปลี่ยนราคา, เปลี่ยนรหัสผ่าน
- **จดหมายเหตุที่ดิน**: ทุกแปลงมีข้อมูลเอกสารสิทธิ์ (ประเภท เลขที่ เนื้อที่ ตำบล/อำเภอ/จังหวัด ผังสี) ผู้ติดต่อเจ้าของ ประวัติราคา และไทม์ไลน์แบบต่อท้ายเท่านั้น (ใคร/เมื่อไร/อะไร) ค้นหาได้ เพิ่มบันทึกได้
- หน้าค้นหาอ่านข้อมูลจาก API กรอง จังหวัด>อำเภอ>ตำบล ราคา ขนาด เอกสารสิทธิ์ เรียงลำดับ รับค่าจากช่องค้นหาหน้าแรก
- หน้ารายละเอียด: สไลด์รูป แผนที่ (placeholder) ตารางเอกสารสิทธิ์ ราคา/ตร.ว. คำนวณผ่อน (ไม่เปิดเผยเลขโฉนด/เบอร์เจ้าของ)
- เครื่องมือ: แปลงหน่วย ไร่-งาน-ตร.ว.-ตร.ม., ผ่อนสินเชื่อ, ค่าโอน (ประมาณการ)
- ความปลอดภัยพื้นฐาน: escape ข้อมูลทุกจุด, จำกัดความถี่การส่งฟอร์ม/ล็อกอิน, กันเส้นทางไฟล์ (path traversal), ตรวจ Origin

## สิ่งที่ยังไม่ได้ทำ (ต้องพัฒนาต่อ)
- เชื่อมต่อ Facebook Ads / Google Ads API จริง และระบบชำระเงินด้วยบัตร/PromptPay (หน้าแอดโปรโมทเป็นโหมดสาธิต)
- แผนที่จริง (Google Maps/Longdo) และปักหมุดแปลง
- แจ้งเตือน SMS / LINE / อีเมล ถึงเจ้าของและแอดมิน
- ฟอร์มสมัครนายหน้า ติดต่อเรา ถามกูรู แจ้งเตือนแอป ยังเป็นโหมดสาธิต (ไม่บันทึก)
- บัญชีสมาชิก/ผู้ใช้หลายแอดมิน สิทธิ์ตามบทบาท, แพ็กเกจพรีเมียม, ระบบบทความ (CMS)
- แอปมือถือ iOS/Android
- โฮสติ้งจริง + HTTPS + โดเมน + สำรองข้อมูลอัตโนมัติ (ควรย้ายไปฐานข้อมูลเมื่อข้อมูลมาก)
- เบอร์โทร/LINE/อีเมลเป็นค่า placeholder (0X-XXX-XXXX) ต้องเปลี่ยนเป็นของจริง
