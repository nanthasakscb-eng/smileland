# ภาพประกาศตัวอย่าง (Blender Cycles)

สคริปต์สร้างภาพทรัพย์ 3 มิติของประกาศตัวอย่าง 30 รายการ (89 ภาพ)

```
pip install bpy            # Blender เป็นโมดูล Python (ใช้ Python 3.13)
python jobs.py             # สร้าง jobs.json จากรายการประกาศ
./drive_all.sh 960 out     # เรนเดอร์ทุกภาพ (ข้ามภาพที่มีแล้ว) ~1.5–3 นาที/ภาพ บน CPU 2 core
python convert.py out ../../public/demo-img   # ปรับโทนภาพถ่าย + webp 400/800/1600
```

- `lib.py` วัสดุ ท้องฟ้า แสง กล้อง ต้นไม้ ต้นมะพร้าว หญ้า
- `arch.py` บ้านชั้นเดียว/2 ชั้น ทาวน์โฮม บ้านไม้ใต้ถุนสูง คอนโด รั้ว ถนน เสาไฟ
- `interior.py` ห้องนั่งเล่น ห้องนอน · `land.py` ที่ดินเปล่า ที่ดินถม ที่นา
- path ในสคริปต์ชี้ไปที่ `/tmp/claude-0/blend` — แก้ให้ตรงเครื่องก่อนใช้
